GET STARTED

从第一份文稿开始。

Texite 是本地 LaTeX 编辑器。先用示例熟悉操作，再打开自己的项目。

三步开始

  1. 下载并安装对应平台的 Texite。Windows 安装包适用于 x64；当前 macOS 安装包适用于 Apple Silicon。
  2. 下载官网提供的样例 ZIP，在项目空间中导入。也可以打开已有项目文件夹。
  3. 打开 main.tex，在 Code 或 Visual 中编辑，点击“编译”查看 PDF。特殊模板请核对所需的引擎、字体和宏包。

网页体验的范围

设备中直接运行 Texite 的前端组件：编辑器、文件树、PDF 工具栏、历史恢复和 AI 差异窗口均沿用软件界面。iPad Pro 是展示容器，并不表示 Texite 已提供 iPadOS 版。

  • 可以直接使用 Code / Visual 编辑、搜索文件、切换视图、备份项目、查看修改历史、预览恢复差异并导出 ZIP。
  • 点击“编译”会载入预制示例 PDF，模拟编译后的效果；即使修改了自定义内容，也可以继续体验预览。面板持续显示“网页未加载编译器，结果为模拟演示”。模拟结果不保证对应当前源码，正式文稿请导出到桌面版编译。
  • AI 使用明确标注的本地预设流程，演示修改文稿、查看差异和撤回。它不理解任意指令，不连接本机 Codex 或在线模型，也不发送文稿。
  • 网页编辑、历史和备份保存在此浏览器的独立本地数据库中，刷新后仍可继续。清理浏览器数据会将它们删除。重要内容请使用导出 ZIP 保存。
  • 播放前会备份当前示例。演示鼠标会移动、点击、逐字输入，字幕解释每一步；点击工作区或按键可随时停止并接手。重置示例前会保留当前项目的备份。
  • 网页不会读取或更改电脑上 Texite 的项目。系统窗口操作、完整 TeX 编译、WebDAV、本机程序连接等功能需要桌面版。

文字较小时，点击设备下方的放大按钮。七种功能可随页面滚动切换，点击左侧介绍中的播放按钮观看对应演示。

七段操作演示

  1. Code 与 Visual 编辑文字，再点击编译查看模拟 PDF。
  2. 右键插入表格、符号；选中文字，通过行内 AI 输入框执行预设修改。
  3. 限定搜索文件范围，查找文字并点击结果，方框标出源码落点。
  4. 先放置光标，再搜索文献并点击插入引用。
  5. 创建项目备份、查看修改差异、预览并恢复版本。
  6. Agent 修改与撤回；对话模式使用预设回答而不改文稿。
  7. 浏览设置中的外观与主题、编辑器文字、编译设置、同步与存储、关于五个选项卡。

编译环境与 AI

安装包内置真实 pdfLaTeX、中文与常用宏包，普通项目可以离线编译。特殊引擎与额外宏包可以从 GitHub Release 下载扩展包后导入。不使用 AI 时，无需登录或连接 AI 服务。

Agent 模式连接本机 Codex 程序；选择实际的可执行程序，而非 ChatGPT.app 应用目录。对话模式支持 Codex 或自定义 API。使用 AI 时，相关文稿可能作为上下文发送到所配置的服务。

macOS 下载与安装

当前公开版本 v0.9.0 尚未经过 Apple 公证。macOS 可能提示无法验证或“应用已损坏”。这不等同于文件必然损坏，但也不应直接忽略安全提示。

请只从 官方 GitHub Release 下载，核对安装包与版本信息。若无法安装，请先阅读 Release 中的说明或向项目反馈；不要关闭全局系统安全保护。公证问题的彻底处理需要正式签名与 Apple 公证流程。
