把 AI 接入你的工作区。

以下步骤用于实际软件；官网平板中的 AI 是预设演示，不会连接真实服务。

01 / 选择方式

你希望 AI 帮你做什么？

Agent CLI

直接修改文稿

连接本机 Agent，读取项目、修改文字、查看差异。使用 CLI 已登录的账户与模型服务。

配置 Agent ↗ 自定义 API

讨论思路与写法

使用自己的 API 地址、模型和密钥，进行解释、润色建议与问答。回复不会自动写入文件。

配置对话 API ↗

Agent 模式连接本机 CLI。对话模式可以选择 Agent CLI，也可以选择自定义 API；使用 CLI 对话时不执行文件修改。

02 / AGENT CLI

以 Codex 为例，连接本机助手。

CLI 是在终端运行的程序。先安装并完成登录，再让 Texite 连接它。无需手动启动 app-server。

  1. 安装 CLI，完成终端登录

    按 Codex 官方安装指南 ↗ 选择 Windows 或 macOS 的安装方式。安装完成后重新打开终端，逐条运行：

    codex --version
codex login
codex login status

    浏览器中完成登录，终端确认已有登录状态后，回到 Texite。账户可用方式与权限以 官方登录说明 ↗ 为准。

  2. 在 Texite 中选择 Agent CLI

    AI 助手 › Agent › 连接设置 › 选择 Agent CLI

    类型选「Codex CLI」，「程序路径 / 命令名」先留空，点击「保存并连接」。Texite 会尝试自动查找本机程序。

    找不到程序？手动填写完整路径

    macOS · 终端

    command -v codex

    将输出路径填入程序路径，例如 /opt/homebrew/bin/codex。以自己电脑的实际输出为准。

    Windows · PowerShell

    where.exe codex.exe

    填写找到的 codex.exe 完整路径。如果通过 npm 安装后只有 codex.cmd 或 codex.ps1，需要找到该安装中的实际 codex.exe，或改用官方独立安装方式；当前连接器直接启动可执行文件。

    选择 CLI 可执行文件，不要选择 ChatGPT.app、Codex.app、安装包或文件夹。路径一栏只填路径，不附加「app-server」或登录命令。

  3. 连接后，试一次小修改

    连接状态显示「已连接」后，在助手底部选择可用模型。先选中一段文字，再发送一个范围明确的要求：

    只润色选中的这段文字，保持公式、引用键和 LaTeX 命令不变。

    完成后查看修改差异，需要时选择「撤回整次修改」。也可以在对话模式选择「Agent CLI」，仅讨论内容。

使用其他 Agent CLI

在「选择 Agent CLI」中切换类型。除 Codex 外，当前预设通过 ACP 连接；请先安装相应 CLI／适配器，并在终端完成该服务的登录或模型配置。

Claude
程序 claude-agent-acp，参数 []。需要 Claude ACP 适配器，仅安装普通 Claude 程序不等于已具备此接口。
Qwen Code
程序 qwen，参数 ["--acp"]。
MiniMax / DeepSeek
选择对应的 OpenCode 预设，程序 opencode，参数 ["acp"]。先在 OpenCode 配置对应服务；默认模型填写该 CLI 提供的完整模型 ID。
自定义 ACP CLI
填写可执行程序及 JSON 数组格式的参数。需要支持 ACP v1、标准输入输出和编辑器文件读写；普通交互式命令并不一定兼容。

参数按预设保留即可。不同 CLI 的文件读写能力存在差异，连接成功后请先做一次小范围修改验证。

连接设置中可调整「空闲自动断开」。默认空闲 5 分钟后断开，执行任务时保持连接，发送下一条指令时自动重连。

03 / 自定义 API

用你自己的模型服务对话。

准备服务商提供的 API 地址、模型 ID 和 API Key。当前支持 OpenAI 兼容的 Chat Completions 接口；仅提供 Responses 或其他协议的端点不能直接接入。

  1. 切换到自定义 API

    AI 助手 › 对话 › 自定义 API › 配置对话 API

    点击配置图标，新增一份配置。

  2. 填写四项配置

    配置名称
    便于自己识别，例如「论文助手」。可以保存多份配置。
    API 地址
    填写服务商的接口基础地址，例如 https://api.openai.com/v1。Texite 会补上 /chat/completions；完整的 Chat Completions 地址也可填写。不要填聊天网页地址或 /responses 地址。
    模型
    填写服务商控制台中可用的准确模型 ID，注意大小写与前缀。不要只填产品昵称。
    API Key
    填写该服务的密钥。本机无鉴权服务可留空；已有密钥时留空会保留原值。需要移除时点击「清除密钥」。

    远程地址须使用 HTTPS。本机服务可以使用 HTTP，例如 http://127.0.0.1:端口/v1，请把端口替换为实际值。

  3. 保存配置，发送一条测试消息

    点击「保存配置」，在助手底部选择刚才保存的 API，再发送「解释一下 LaTeX 中 cite 和 ref 的区别」。收到回复即完成验证；保存配置本身不代表接口已经连接成功。

桌面版使用系统加密保存密钥；系统加密不可用时仅在本次运行保留。AI 请求会把相关文稿作为上下文发送到所选服务，服务权限与额度由对应账户管理。

04 / 常见问题

连接不顺利？从这里检查。

提示 EACCES，或选择了 ChatGPT.app 后无法连接

选中的通常是应用包或无执行权限的文件。重新运行上面的路径查找命令，选择 CLI 可执行文件。Mac 上的 /Applications/ChatGPT.app 不能直接作为 CLI 启动；不要为了连接而修改整个应用包的权限。

终端里可以运行，Texite 却提示找不到程序

桌面程序与终端的程序搜索路径可能不同。在「选择 Agent CLI」中填写完整文件路径，安装或升级 CLI 后重启 Texite。Windows 需要实际的 codex.exe；Mac 使用 command -v codex 的输出。

提示未登录，或连接后没有可用模型

先在同一系统账户下的终端确认 CLI 可以正常使用。Codex 可运行 codex login status 检查，再运行 codex login 登录。其他 CLI 需完成各自的认证与模型配置，随后回到 Texite 刷新连接。

API 返回 401 / 403 / 404 / 429

401 / 403：检查密钥、模型权限及服务商访问限制。404：检查基础地址、接口路径和模型 ID。429：检查额度与速率限制，稍后重试。具体原因以服务商返回的信息为准。

API 没有返回文本，或提示流式数据无效

确认服务支持 Chat Completions，且所选模型支持文本回复与流式输出。仅兼容 Responses、原生 Messages 等协议的服务不能直接填写；需要提供 Chat Completions 兼容端点。

配置了 API，为什么不能自动改文件？

自定义 API 属于对话模式。要让助手直接修改项目，请切换到 Agent 模式并连接本机 CLI。API Key 配置不会自动安装或登录 CLI。

连接完成，把注意力放回文稿。
